# Analisis Platform

| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| Bahasa utama | HTML, CSS, JavaScript/TypeScript (backend: PHP, Node.js, Python) | Java, C#, C++, Python; JavaScript via Electron | Kotlin/Java (Android), Swift (iOS); Flutter (Dart), React Native |
| Arsitektur | Client-server; browser sebagai client, server memproses dan menyimpan data | Berjalan langsung di OS, standalone atau terhubung ke server | Aplikasi di perangkat bergerak, umumnya terhubung ke API/backend, memakai SDK dan sensor perangkat |
| Cara distribusi | Diakses lewat URL/browser, tanpa instalasi | Installer (.exe, .dmg, .deb) atau toko aplikasi | Google Play Store, Apple App Store, atau APK |
| Keunggulan | Lintas platform, mudah diperbarui, tanpa instalasi | Performa tinggi, akses penuh ke sumber daya sistem, bisa offline | Portabel, akses sensor (GPS, kamera), notifikasi push, jangkauan luas |
| Keterbatasan | Bergantung pada internet dan browser, akses perangkat keras terbatas | Harus diinstal dan dibuat per OS, pembaruan lebih repot | Layar kecil, baterai terbatas, proses review toko aplikasi, fragmentasi perangkat |
| Contoh aplikasi | Google Docs, Tokopedia (web), Wikipedia | Microsoft Word, VS Code, Photoshop | WhatsApp, Gojek, Instagram |
